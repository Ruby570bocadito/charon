## Decisiones tomadas

- **El GIF se genera con el mismo principio que el PNG** (salidas reales
  renderizadas, no mocks): reutiliza el parser ANSI de
  `make_screenshot.py` vía import — una sola fuente de verdad visual.
- **El GIF se versiona en el repo** (463 KB): GitHub lo renderiza en el
  README directamente y el beneficio de imagen supera el coste; el script
  permite regenerarlo con otra densidad si el tamaño creciera.
- **`ccache` es comando de primera clase** (no flag de `as`): separa
  autenticación (escribir material) de auditoría (leerlo), simétrico con
  `keytab`.
- **La validez del ticket se calcula contra el reloj local** (como klist):
  se documenta en el código que un reloj torcido produce un estado
  torcido — inherente a una herramienta offline.
